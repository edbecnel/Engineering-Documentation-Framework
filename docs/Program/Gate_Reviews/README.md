# Gate Reviews

## Purpose

One **Engineering Gate Review Record (EGR)** Markdown file per program gate, per [EGR-0001](../../Specifications/EGR-0001-Engineering-Gate-Review-Records.md).

Record **Active overrides** when an Open gate has a Governed Dependency Override. That column is the project’s governance-debt list for deferred blocking dependencies. A downstream EGR is not required merely because a GDO exists.

## Index

| Gate ID | File | Status | Active overrides |
|---|---|---|---|
| _None in framework reference repo_ | | | |

Adopting projects add rows here when EGR files are created.
